## The rule

One prompt a day from the 100 Days CSS challenge, one pen, finished the same
day. No carrying work over, no library, and wherever possible no JavaScript —
if a transition could be expressed in keyframes and transforms, it had to be.

## What it actually taught

Three things, none of which I would have got from a tutorial:

1. **Easing is the whole message.** The same displacement reads as playful,
   mechanical or broken depending only on the curve. Most of my later work uses
   a narrow set of curves for exactly this reason.
2. **Compositing discipline.** Restricting yourself to `transform` and
   `opacity` is not a performance micro-optimisation, it is a constraint that
   forces the animation to be about position and presence rather than layout.
3. **Stagger carries structure.** A group of elements arriving together is
   noise; the same group arriving in sequence tells the viewer what is grouped
   with what.

## Where it shows up

The six named motions on this site — Settle, Repel, Wipe, Magnet, Panel,
Track — are the surviving vocabulary from those ninety-nine days, reduced to
the set worth reusing.
